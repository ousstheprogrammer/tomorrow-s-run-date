# Tomorrow's Run Date

Create a beautiful, funny and romantic one-page interactive website for my girlfriend Aicha.

The entire page should have ONE simple purpose:

Ask Aicha:

“AIcha, will you go running with me tomorrow? 🏃‍♂️❤️”

Make it feel like a cute surprise from her boyfriend.

STYLE:

- Romantic + sporty

- Dark black background

- Red/pink romantic accents

- Smooth animations everywhere

- Floating hearts ❤️

- Running emojis 🏃‍♂️🏃‍♀️

- Cute modern typography

- Mobile-first

- Premium but simple

- Use Framer Motion

- Add confetti when she accepts

HERO SECTION:

Show:

“HEY AICHA ❤️”

Then animated text:

“I have an important question for you…”

After 1 second:

“Will you go running with me tomorrow? 🏃‍♂️❤️”

Under it:

“Just you + me + a little suffering + lots of laughs 😂”

Then display two big buttons:

❤️ YES, LET'S RUN

😈 NO

YES BUTTON:

When Aicha clicks YES:

1. Trigger a huge confetti animation.

2. Make hearts float across the screen.

3. Play a cute success animation.

4. Change the title to:

“YEEEEES! ❤️🏃‍♂️”

Then:

“I knew you couldn't resist running with your favorite trainer 😎”

Then:

“Tomorrow = You + Me + Running + Good vibes ❤️”

Then display:

“OUR RUNNING DATE IS OFFICIALLY BOOKED 🏃‍♀️❤️🏃‍♂️”

Add a cute animated countdown-style card:

“TOMORROW'S MISSION”

🏃‍♀️ Run together

😂 Laugh together

💪 Get stronger together

❤️ Make memories together

Then final message:

“Honestly, I don't care how fast we run…”

“I just want to run beside you. ❤️”

NO BUTTON — IMPORTANT:

The NO button should be playful and impossible to click.

When the user moves their mouse toward the NO button, immediately move the button to another random position.

On mobile, when she tries to tap the NO button, move it before the tap can register.

The button should stay inside the visible game area and never move outside the screen.

Make the movement smooth and funny using spring-like animation.

Every time she tries to click NO, display a different funny message above the buttons.

Examples:

Attempt 1:

“Are you sure, Aicha? 👀”

Attempt 2:

“Hmm… I don't think you really mean that 😂”

Attempt 3:

“Nice try 😭”

Attempt 4:

“NO button.exe has stopped working 💀”

Attempt 5:

“Aicha… please 😭❤️”

Attempt 6:

“Your trainer is disappointed 😔😂”

Attempt 7:

“Okay okay… I'll give you one more chance 😭”

Attempt 8:

“THE NO BUTTON REFUSES TO COOPERATE 😂”

After several attempts, make the NO button become smaller and the YES button become larger.

Eventually show:

“Okay Aicha… apparently NO isn't an option 😂❤️”

Then make the YES button huge:

“YES ❤️🏃‍♂️”

When she finally clicks YES, trigger the full celebration.

ANIMATION DETAILS:

- Background has slowly floating hearts.

- Small running emojis occasionally move across the screen.

- Buttons have subtle hover animations.

- YES button gently pulses.

- NO button dodges the cursor/finger.

- Smooth transitions between every state.

- Confetti should burst from the center when YES is clicked.

- Add a subtle heart particle effect.

- Use spring animations for the NO button.

- Respect prefers-reduced-motion.

FINAL ROMANTIC MESSAGE:

After the celebration, show:

“Aicha ❤️”

“Thank you for saying yes.”

Then:

“I know it's just a run…”

“But every little thing is better when I get to do it with you.”

Then:

“Tomorrow, don't worry about your pace.”

“Just stay beside me. ❤️”

Final large text:

“SEE YOU TOMORROW, MY RUNNING PARTNER 🏃‍♀️❤️🏃‍♂️”

And underneath:

“Your favorite trainer 😎”

Make everything work perfectly on desktop and mobile.

Do NOT ask for her name.

Her name is Aicha.

Keep the whole experience short, funny and romantic — around 30–60 seconds of interaction.
